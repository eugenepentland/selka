# Internals notes

How the compiler does what the user guides describe: cache keys and stores, the passes, measurements, and the edge cases
of rules that the guides state in one line. Each file here carries the name of the guide it belongs to
(`docs/NAME.md` or `docs/tooling/NAME.md`) and uses the same headings.

These pages are for people who work on the compiler. They are not part of the documentation site, and `selka docs` does
not print them. The text was moved here unchanged from the guides on 20 November 2026, when the guides were cut down.
