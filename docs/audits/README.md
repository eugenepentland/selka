# Historical compiler audits

These dated reports and figures record compiler development decisions. Their
commands, paths, and performance claims refer to the revisions they name.

Large raw runs, generated dumps, application copies, and compressed receipts
remain in the local development archive. References to those omitted artifacts
are historical records, not instructions for building the current compiler.

For the public measurements and their retained raw samples, see
[benchmarks](../benchmarks.md). The [repository contents](../publication.md)
describe what is included in this snapshot.
