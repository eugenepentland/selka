The emitted LLVM nominally has 56-byte memcpy operations around exchange, but native scalar replacement eliminated them. Neither helper copies owned list entries, copies the fields table, allocates memory or performs RC. table.set may grow the table using ordinary allocation; it does not run Lox GC. Payload extraction reads two words (16 bytes) for env and three words (24 bytes) for instance; payload restore writes only those words and the8-byte tag.

Residual placeholder-drop machinery remains: env0x106bdb1–0x106bdc4 and instance0x1069af0–0x1069b04 reread tag1 byte plus five8-byte union payload words (41 bytes) before dispatching a generic old-Obj drop. These are loads, not whole-Obj copies or writes. The tag is free on every valid execution, so normal paths perform no drop calls; native contains possible myl_core_drop_owned calls/tailcall only behind tag dispatch. Placeholder creation occurs env0x106bd94/instance0x1069ad6; restoration env0x106bdc8–0x106bdd3/instance0x1069b08–0x1069b17.

Prevalidation is inlined in both. Env checks nonnegative object ref/range/kind and signed local index lower/upper range. Exchange object-range and second kind checks disappeared. The subsequent unsigned index-normalization branch at0x106bd9b remains; negative index handling0x106be1c–0x106be2c is supported and must remain semantically intact. Instance repeats object-list length check after table.set at0x1069ae6–0x1069aee, then retains old-free drop dispatch. These are bounded scalar/check costs, not the former large-copy bottleneck.

Native call sites: env5 (execute0x105ec29, evaluate0x1065f5e, define0x10671d5, call_value0x106f822, bind0x1070214); instance2 (vm.run0x105b865, interpreter.evaluate0x106569f). Fresh enter_function no longer calls set_env_slot. Setter requirements/cold validation helpers do not remain separate calls on the success path.

Pinned Zig comparison uses actual native offsets and DWARF attribution; the historic original DWARF source path is unavailable, so native evidence is primary. Zig resolved local assignment is inlined:0x10859fd loads slots pointer,0x1085a17 loads a16-byte Value and0x1085a1d stores it directly. No exchange/restore/drop exists. Zig property setter passes the fields table address to table.Table.set at0x1085b52; no Obj copying or restoration. Zig omits the checked local handle/kind/index bounds performed by MyLang: this is a safety-contract difference, not a proposed removal. Both retain one table setter call for field writes (MyLang table.set486 bytes; Zig Table.set660 bytes); sizes alone do not imply relative performance.

Recommendation order: continue already-owned inlining/arithmetic/discard-local work first. Existing mutation lowering has removed large copies and allocator traffic. A later bounded checked compiler improvement could prove that payload-list/table mutation cannot alter the free-placeholder object tag, eliminating redundant union loads/drop dispatch while retaining validation, negative indexing, alias-visible writes and failure ordering. Separately proving that table.set cannot mutate objects length could remove the second instance range check. Neither is presently measured, and no setter prototype is authorized by this audit.
