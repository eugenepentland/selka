# E1 evidence

Everything here is generated by a run, never written by hand — except this file
and `dev-pilots.md`, which reads the generated documents.

| Path | What it is |
| --- | --- |
| `runs/<run_id>.json` | one `e1-observation-v1` attempt: prompt, identities, timings, grading, events, cache probes, budgets |
| `dev-pilots.md` | the readout of the development pilots actually run |
| `dsh-blocked-2026-09-21.txt` | the verbatim output that blocked the model-driven arm |

A run's scratch directory lives under `../work/<run_id>/` (gitignored) and holds
the candidate tree, the prompt, the solver's captured stdout/stderr and the raw
`events.jsonl`. The observation is the summary; the raw event log is kept so a
claim can be re-derived from the events rather than from the transcript.

Regenerate the readout numbers with:

```bash
python3 - <<'PY'
import json, glob
for path in sorted(glob.glob('evidence/runs/*.json')):
    d = json.load(open(path))
    print(d['status'], d['task']['id'], d['arm']['name'], d['timings']['wall_seconds'])
PY
```
