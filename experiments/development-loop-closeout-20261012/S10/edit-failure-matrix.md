# Independent matrix and evidence boundaries

Baseline C0 and final integration use the authoritative action inventory. Global
completion requires exact current groups, stable inputs and zero process status;
a quick selection or synthetic fixture cannot replace this verdict. Current
coverage is in acceptance-report.md, never inferred from an old group count.

| Case | Independent comparison / rejection evidence | Timing interpretation |
| --- | --- | --- |
| Unchanged one-shot/retained | Forced gate vs receipt reuse; two retained requests archived with action states and snapshot counters | Operational totals including validation/reporting; isolate later for targets |
| Test/fixture edits incl add/delete/rename | S03 exact named parity, mutated format oracle causes failure; final declared dependency fixture tests | Cold compile/RSS plus warm responsible-only selection pending |
| Documentation/tooling/pure helper | Complete inventory metadata/group contracts and S04 real scalar producer identity tests | No heuristic selection qualifies reuse |
| Semantic/runtime/lifetime/mode/ABI | Conservative compiler fallback and existing identity qualification tests; final full gate executes | Matched baseline rebuild if semantics change; no tooling attribution for lifetime change |
| Components/seeds/protocol | S09 bridge and external seed contract; S04 mutation/schema/missing manifest fixtures | Full bootstrap/36-row ratios remain open |
| Revert/second tree | Store/snapshot/session source-revert and path identity tests; explicit real second-tree evidence pending | No portable performance claim from path normalization |
| Cold tiers | Fresh private verification/project/runtime/compiler stores as specified; never wipe shared stores | Report borrowed global/native warmth honestly |
| Concurrent/cancel | S02 process lifecycle fixtures and real claim/store coordination tests | Queue time separate; execution clocks start after admission |
| Timeout/crash/publication | Detached tree cleanup, late publication, failed forced refresh, retry fixtures | Incomplete process output never success |
| Corrupt/evicted/watch lost | Exact receipt/snapshot/store fixtures, pin/lease retention checks | Recompute or fail; metadata alone cannot prove content |
| ABA/symlink/PATH/negative lookup | Snapshot identity/event and session runtime guard fixtures | Bounded cause diagnostics preserve fail-closed state |
| Profiles/fuzz/Juice | S05 exact coverage/partial/profile tests and workload output/completed-unit smoke | Instruction counts cannot satisfy wall-clock ratio |
| Large inputs/resources | S06 shared-root/synthetic discovery cases; S07 corpus inventories/artifact bytes | Reject slow small cases; report RSS/fd/retained bytes |
| Self-host stages | Port owned external source remains read-only; authenticated parity/stages required | DL7 open until complete bootstrap and every required ratio |

Each row must be reported as independent real execution, targeted safety fixture,
or unqualified. Safety fixtures prove their bounded contract, not every possible
repository edit. All final fixture-based proof still needs execution against the
integrated final source. No missing row is removed to obtain a completion claim.
