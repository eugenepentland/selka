# A05 scalar interior mut writeback correction

Support7 (`bed11cf3bf3102ffec44487e431a1573fdf02ad5`, compiler SHA256 `540283317dab8009ba38f7bc13a521b1b5048cff99701498acd56da7902259ef`) miscompiled two scalar writes into one list. The ordinary compiler mode produced `[11, 22]`; checked ownership produced `[1, 22]`. The named scalar callback plus scalar fields of a managed record refused with `E_ZERO_RC_LOWERING`. Both failures reproduce through the actual guest test runner and independent direct-main programs. `support7-results.json` retains every command and result, and `support7-values-*.ll` preserves the generated comparison. Initial harness conditional-syntax mistakes are separately retained as `support7-initial-harness-results.json` and are not compiler failures.

The isolated candidate starts at integration `d01f772cd0cfa823a9ec6a8838aaf5c4856710b4`. It changes only `callTarget` in `src/core/build.zig`: prepare a transferred ownership path for a managed leaf, while scalar leaves keep the ordinary current-root writeback. Reusing a saved parent for both scalar writes discarded the first update; reconstructing managed record siblings from that same stale parent could demand a forbidden retain. The checked argument type supplies the managed predicate without reading a nonexistent SSA payload for Unit. All argument evaluation, overlap, captured-path publication and ancestor invalidation checks remain in place. This does not allow multiple managed child loans from one root.

Three registered tests pass (`scalar-mut-build-final.log`): five native modes, all original `frontend_mut.my` assertions unchanged, dynamic list indices, nested list and dictionary siblings, named callback written order, independent snapshots, managed-leaf transfer controls, overlap/bounds before the callback executes, a same-root managed-child refusal, and immutable borrowed-input refusal. The original guest test file also passes 10/10 tests in each of five modes, with no unsupported cases (`candidate-results.json`). Direct-main dynamic and named reproducers pass; the encoded `[11,22]` result is 132. All three counted direct runs have zero runtime RC events and zero live managed bytes at exit. Registered native runs also audit emitted LLVM and managed counters. The first registered test attempt passed the positive release case but caught a fixture argv indexing error; that log is retained separately.

The private candidate compiler identity and production overlay hash appear in `candidate-results.json`; exact source and test hashes are in `source-hashes.json`. These results qualify this isolated fix, not a new common C1 or default/retirement milestone. A02's distinct managed indirect-call return ownership fix is independent and must be integrated separately.
