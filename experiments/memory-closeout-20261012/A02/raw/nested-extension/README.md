# Nested extension qualification artifacts

`summary.json` pins the successful integrated-base feature qualification.
`registered.json` records the one focused test selection, compiler/source hashes
and staged component boundary. `native-results.json` retains full five-mode
counters, outputs, traps and LLVM/symbol checks. `ancestor-controls.json` records
two refusals and five counted explicit-copy executions. `before/` preserves the
earlier abort and ordinary snapshot controls, never relabeled as final results.

The `*-runner.txt` files are verbatim scratch orchestration scripts retained for
provenance, not portable replay entrypoints. Use A02 `list_methods.py` with a
frozen full compiler installation and new output directory under shared build
admission. The ancestor `.my` files are standalone replay sources. Focused
results do not replace the coordinator's full verification gate.
