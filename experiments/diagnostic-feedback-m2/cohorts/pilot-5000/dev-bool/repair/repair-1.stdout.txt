Fixed. The bug was a type error: `above` declared `-> int` but returned the `bool` from `a > b`. I replaced the comparison-return with an explicit `if`/`return 1`/`return 0`.

```python
def above(a: int, b: int) -> int:
    if a > b:
        return 1
    return 0
```

Command and result:

```
$ bin/mylang check project/main.my && bin/mylang run project/main.my -- <args>
check OK
5 2  -> 1
2 5  -> 0
3 3  -> 0
-7 2 -> 0
```

Both `public/expected.json` cases match (`"1\n"` and `"0\n"`), and `check` now exits 0.
