hashes. Compressed receipts retain exact example commands, original failures,
four corrected GC-stress/RC outcomes on QBE/LLVM, documentation reports,
feature coverage and whole-tree Guardian. The example returns 142 by design;
successful validation checks that status and its `142` output explicitly.

The source examples preserve the former shared-list assumption and its independent
value correction. Documentation tests ran all 13 runnable blocks with inherited GC
and inherited RC; the explicit legacy-sharing block normalizes to GC as required.
These are focused documentation checks, not complete Stage 4 acceptance.
