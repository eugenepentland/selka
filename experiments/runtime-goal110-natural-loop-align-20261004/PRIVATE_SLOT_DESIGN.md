# Private scalar-slot ranges: bounded design, not an implementation

Use a fresh integrated `1a398063` sibling with the reviewed final-floor-result annotation prerequisite. Preserve the guarded bounded-bias lowering's early return in `checkedDivRem`. Do not carry the unadopted natural-loop alignment policy or change frozen fixtures. This analysis belongs to the LLVM translator after IL rewrites; QBE IL and guest accounting remain unchanged.

The current translator's `MemoryClasses.frame` is an alias class, not proof that a particular slot is private. `constantStackSlots` recognizes single-definition `alloc8 8` roots but explicitly permits historical escapes and resets reaching stores. Reuse `definitionCounts`, parsed `Instruction` identities and CFG successor/dominance infrastructure, not the broad frame class as range authority.

Prove an exact 8-byte allocation root and its zero-offset, singly defined `copy` aliases. Audit every use of that root/alias throughout the activation: allow only pointer copies and exact full-width `loadl`/`storel` address operands. Reject address arithmetic, pointer-valued stores, calls/returns, captures, blits, narrow accesses, indirect or ambiguous aliases, multiple pointer definitions and any other use. A copied address that escapes invalidates the whole root. Do not infer uniqueness from a temporary's name, frame class, benchmark, or memory layout.

For every full-width write to an eligible root, prove a nonnegative upper bound on the exact value at that store. Initial leaves are nonnegative integer literals and the exact final-add `Instruction` certified by `hints.floor_results`; the raw `rem` definition never gains its later corrected result's bound. Follow same-block value copies and the nearest preceding store to another independently proved private scratch root, stopping at a reassignment, unknown writer, block boundary, cyclic dependency or work limit. Existing zero-bool IL stores the exact certified floor result to `%s0`, immediately loads it, then stores it through a copy of `%l2`; this local chain can be proved without declaring all values ever written to `%s0` bounded. A seeded initializer loaded from a parameter remains unknown and rejects the persistent root's all-write range.

Union all proven writes using the largest unsigned exclusive bound. Require explicit definite initialization before every annotated load: initially use an approved store that dominates that load, including instruction order in the same block. Refuse loads where no such dominating initializing write exists. The all-write proof is activation-wide and conservative even for unreachable writes. Do not bootstrap a candidate root's proof from a load already assumed bounded by that same candidate; leaves must terminate at literals or exact floor certificates. This avoids circular induction and permits bounded local scratch propagation rather than a new general memory dataflow solver.

Return a map from exact `*const Instruction` load definitions to upper bounds. Emit `icmp ult` and `llvm.assume` on the just-loaded value downstream of ordinary `onLoad`/definition emission, matching the reviewed floor-result emission convention. No upstream pseudo-call, observable runtime work, branch change, new arithmetic flags, or guest step/frame/allocation charge is introduced. Never attach a whole-temp fact to a mutable IL destination. Later same-temp reassignment is independent. Bound CFG size and charge alias scans, definition searches, dominance walks and value-chain traversal to a single finite analysis budget; exhausted or ambiguous proofs emit no fact.

Validate positive owned slots through copies/scratch, different positive floor divisors, all initialized incoming writes, loops and recursive activations. Refusals include unknown/negative initializer, one unknown/negative later write, alias escape through copy/call/return/pointer store, nonzero pointer arithmetic, narrow write/blit, missing initialization on one incoming path, load-before-store, raw remainder, stale/reassigned temporary, unknown incoming scratch write, and cyclic proof dependencies. Keep signed overflow/division-zero/negative-dividend controls and complete accounted/GC/step/frame/memory refusal streams from the existing native matrix. Inspect actual O3/fullLTO IL/IR and both fast/fallback loops before timing.

If a later checksum-like recurrence loads `x` with `0 <= x < D` and a separately proved boolean `b` with `0 <= b <= 1`, a successful checked addition has `0 <= x+b <= D`. Its final floor remainder is `select(x+b >= D, x+b-D, x+b)`. More generally, two independently bounded operands can justify this when their exact wide sum is below `2D`. This is a later proof/lowering question: retain the checked-add trap and ordinary signed floor paths for unknown increments, use wide host arithmetic at `D=1`/`I64MAX` boundaries, and first inspect whether LLVM already simplifies the existing remainder once load bounds are visible. No benchmark-specific conditional-subtraction rewrite is proposed here.
