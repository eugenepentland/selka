Base common compiler: 1994cb76e266080d971be6f41e98fba5707234dd. Production/regression commit: 44af62b3ffccf7658858181a79dd0566bfe12f9a.

`myl_core_ir_str_append_char` previously saved six registers and allocated 24 bytes of stack on every scalar append, even the ASCII spare-capacity path. Small CSV executes about 354 scalar appends per job. The zero-RC-only general path is now a private noinline helper receiving the already checked width. It captures exactly that scalar into private scratch before cursor reset, allocation or alias free. The public helper's signature, checked width order, ASCII guards, shared append cache/counter updates and ordinary RC body are unchanged. No compiler ownership proof or ABI is widened.

Candidate machine code has no stack instructions on the ASCII path and tail-jumps to the general helper for Unicode/static/cursor/growth paths. Exact disassembly excerpts are archived in trial01. No instruction-count estimate is substituted for measured time.
