    (note
      "U1"
      "Derived from the Straps base board (KiCad 'Black_Canyon_Base_Board', U7 block). Supply is a single 3.3 V port; the board's NFM31KC223R1H3L feedthrough filter (C76) is dropped because the destination rail is a dedicated LT3045 with no other loads to isolate against. VCC bypass is TI's reference-design arrangement, unchanged from the board: ONE 1 uF per supply pin and nothing else — no parallel 100 nF bank and no bulk reservoir (the EVM has neither; on the intended host the LT3045's output cap is the reservoir). VREGIN (pin 10) is a BYPASS pin, not a supply — the datasheet calls it the 'input reference path regulator output' and asks only for a 1 uF cap to ground close to the pin (C63) — so it is correctly left off the 3.3 V rail here. bcuda-synth-lmx2595 (retired here 2026-08-07) and cyclops-xband-lo (fixed 2026-08-07) both tied pin 10 to their VCC rail instead.")
    (note
      "U1"
      "REFERENCE SOURCE — ACTION REQUIRED ON THE BOARD. This module now expects a DIFFERENTIAL reference on REF_P/REF_N (100R across the pair, 0.1 uF into each leg). The fabbed straps board cannot feed that: its reference is the SI53361 clock buffer's single-ended LVCMOS Q0 through a 33R series resistor (R52). Driving REF_P from that source and leaving REF_N open would be worse than the single-ended circuit it replaced, because the 100R now sits across a pair with only one leg driven. To use this module the board needs a genuine differential source — an LVDS/LVPECL output (the barracuda board takes its 100 MHz pair off an LMK05318B) or a single-ended-to-differential conversion ahead of it. R52 and R38 both go away in that rework.")
    (note
      "U1"
      "LO OUTPUT MOVED TO RFOUTA. The straps board takes its LO off RFOUTB and leaves RFOUTA open and unbiased; here the whole network — 18 nH choke L7, 0.01 uF bypass C68, the two 50R pull-ups, the AC-coupled 50R idle-leg termination and the 0.01 uF output block C70 — sits on port A instead. Both buffers are fed from the same VCO/divider chain, so this costs nothing in performance.")
    (note
      "U1"
      "PORT-B DISPOSITION — UNUSED, UNPOPULATED, DISABLED (user decision 2026-08-31). RFOUTBP (19) and RFOUTBM (18) carry NO external network: no 50R pull-ups, no bias tee, no DC block — both nets are deliberate dead-end stubs ending at the QFN pads (the schematic warnings naming them are expected). The FIRMWARE CONTRACT keeps the buffer powered down: the release register image sets OUTB_PD = 1 and never selects OUTB_MUX = channel divider/SysRef (LMX2595.pdf Table 9 — so the channel divider is not spuriously powered either); port B must not be enabled on this hardware, because LMX2595.pdf Pin Functions p.7 requires a ~50R pull-up to VCC on each leg and section 10.1 p.68 requires the complementary leg to carry the same load before the buffer may drive. With OUTB_PD = 1 the open-collector output stage is off and sources no current, so the unpowered, unloaded pins are electrically inert; the datasheet's own EC-table note measures the device with the 'unused port terminated' only because both ports are ENABLED in that characterization. Bringing port B up later is a REWORK, not a register write: fit the port-B bias tee (18 nH choke + 0.01 uF off V_3V3), 50R pull-ups on both legs, a DC block on BP and a 50R idle-leg termination on BM — then re-open requirements b520171a/6bdc7a58/1666d0da, whose 2026-08-31 waivers are conditioned on the port staying disabled.")
    (note
      "U1"
      "PORT-A BIAS TEE, per the TI LMX2594/95 EVM (which feeds its 50R pull-ups through an 18 nH choke — L2 — from VccRF): an 18 nH choke from V_3V3 into the 0.01 uF-bypassed bias node LO_BIAS_A. The node needs BOTH parts — the choke alone does not make an RF ground. The EVM and the straps board both give the choke its own rail (VccRF / +3.3V_RF); here it rides the module's single V_3V3 port, which on a board whose 3.3 V is already a dedicated low-noise LDO (barracuda's V_3V3_LMX) is the same node either way. CORRECTED 2026-08-31: an earlier revision of this note described a second (port-B) bias tee that was never instantiated — port B is unpopulated and disabled by disposition; see the PORT-B DISPOSITION note.")
    (note
      "U1"

Electrically identical series branch; the cap-first order keeps the resistor's noisy node off the high-impedance CPOUT pin.")
