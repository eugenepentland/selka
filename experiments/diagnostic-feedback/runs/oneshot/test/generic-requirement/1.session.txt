**Change:** In `project/main.my`, removed the invalid generic clause from `pick`, changing `def pick[T: Sortable](values: list[int], index: int) -> int:` to `def pick(values: list[int], index: int) -> int:`. The type parameter `T` appeared nowhere in the signature (nothing to infer it from) and `Sortable` was not a valid bound; since it was unused, dropping it is the minimal fix. The body still returns `values[index]`, so `pick([4, 9, 1], 1)` yields `9`.

**Command:** `bin/mylang run project/main.my` → printed `9`, exit code `0`.
