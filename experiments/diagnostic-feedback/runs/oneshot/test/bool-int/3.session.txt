Change: in `project/main.my`, `above` was declared `-> int` but returned the `bool` expression `a > b`. I kept the `int` return type the printing contract needs and returned integer literals instead:

```python
def above(a: int, b: int) -> int:
    if a > b:
        return 1
    return 0
```
