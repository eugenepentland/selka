**What I changed:** In `project/main.my`, I removed the invalid generic requirement from `highest` and `highest_of`. Both were declared as `def highest[T: Comparable](values: list[int]) -> int:`, which the checker rejected with `E_GENERIC_REQUIREMENT: unknown requirement; expected copy, equality, integer, codec, storable, or a declared constraint`. Since both signatures already take a concrete `list[int]` and the type parameter was unused, the fix was to drop `[T: Comparable]`; no other lines were touched.

**Commands and results:**
- `bin/mylang check project/main.my` → exit 0 (was exit 1 before the fix)
- `bin/mylang run project/main.my -- 1 3 2` → stdout `3`, exit 0 (matches `public/expected.json`)
- `bin/mylang run project/main.my -- 5 5 5` → stdout `5`, exit 0 (matches)
- `bin/mylang run project/main.my -- -5 -1 -3` → stdout `-1`, exit 0 (extra edge case)
