**What changed** — `project/main.my`, in `exceeds` only. The original code assigned the boolean `a > b` to `bigger` and returned it, which the checker rejected (`main.my:14:5: error[E_TYPE]: expected int, found bool`) and which would have printed `True`/`False` rather than `1`/`0`. It now returns the integer directly:

```python
def exceeds(a: int, b: int) -> int:
    if a > b:
        return 1
    return 0
```

- `bin/mylang run project/main.my -- 5 2` → `1`
- `bin/mylang run project/main.my -- 2 5` → `0`
