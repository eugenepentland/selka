## What I changed

**`project/main.my`** — added the missing `case Shape.square(side)` arm to `area`, returning `side * side`. The match was non-exhaustive (`E_INCOMPLETE_MATCH`), so the program failed the checker; the new arm makes it compile and gives squares `r*r` while circles keep `3*r*r`.

```python
def area(shape: Shape) -> int:
    match shape:
        case Shape.circle(radius):
            return 3 * radius * radius
        case Shape.square(side):
            return side * side
```
