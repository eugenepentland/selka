Fixed. The `match` in `area` was missing the `square` arm, so the checker rejected it with `E_INCOMPLETE_MATCH`.

**Change** (`project/main.my`, one arm added):

```python
def area(shape: Shape) -> int:
    match shape:
        case Shape.circle(radius):
            return 3 * radius * radius
        case Shape.square(side):
            return side * side
```

**Commands and results:**

- `bin/mylang check project/main.my` → exit 0, no diagnostics
- `bin/mylang run project/main.my -- circle 2` → `12`, exit 0
- `bin/mylang run project/main.my -- square 3` → `9`, exit 0

Extra sanity inputs also matched the required formulas: `circle 5` → `75`, `square 7` → `49`, `square 0` → `0`, `circle 0` → `0`.
