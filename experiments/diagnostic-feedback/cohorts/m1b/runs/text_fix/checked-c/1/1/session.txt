## What I changed

`project/main.my` — only `main`; `decode` is untouched:

```mylang
def main(args: list[str], out: Stream) -> int:
    base = decode(args[0])
    match base:
        case Ok(value):
            out.print(value + value + 10)
        case Err(_):
            out.print(0)
    return 0
```

The old body reused the `Result` twice (`base + base + 10`), which the compiler rejects with `E_RESULT_CONSUMED`, and it never handled `Err`. The fix consumes the `Result` exactly once with a `match`: the `Ok` payload is printed, and a non-integer argument (which `int()` returns `None` for, i.e. `Err`) prints `0`.

Note on the arithmetic: the checked example `41 → 92` pins it to `value + value + 10` (the expression the original body already had), not `value + 10`; the other checked example `0 → 10` agrees with both.
