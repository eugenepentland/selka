## What I changed

`project/main.my` only. The bug was in `main`: it added `-3` to `to_int(...)` directly, but `to_int` returns a `Result[int, str]`, not an `int`. I unwrapped it with a `match`, so:

- `Ok(value)` → prints `-3 + value`
- `Err(_)` → prints `-1` (argument not an integer)
- `len(args) == 0` → prints `-1` instead of trapping on `args[0]`

`to_int` was already correct (`int(raw)` yields `Option[int]`, which it maps to `Ok`/`Err`), so I left it unchanged.
