# S4-E emission package, 2026-10-06

Implementation checkpoint; qualification is in progress. This is not an S4 exit report.

The emitter directly renders source-module, generic-instance, compiler-helper and entry units. Program functions and calls use fastcc; cross-unit definitions and declarations are hidden. Unit-local first-use numbering covers strings, dictionary descriptors, layout descriptors, trap sites, ranges/loops/debug metadata and descriptor graph closures; each unit's zero constant has its own maximum. A lexical LLVM symbol walk preserves source string contents while closing and renumbering value/render descriptors. Compiler-authorized equality/render adapters have stable content-derived symbols. Runtime alwaysinline helpers are included only through their reached closure.

Every site record carries its original path. The sole existing runtime ABI change is the site-index-to-pointer conversion for trap, assert, ordinary and preserve-most error tracing, and the existing effect-site carrier `myl_core_io_at`. The error trace's origin/ring store pointers; the property runner resets the origin to NULL. The DWARF reader searches every compile unit and resolves file-table entries. Runtime and float object builders publish random owned partials atomically. Driver link dependencies union each unit's number/math flags. `--emit-llvm` preserves whole-module output for inspection; normal linking uses independent units. `ir.zig` is unchanged.

Six new tests cover deterministic repeats; own body/check/line edits; an inlined public helper changing only itself and its caller; unrelated type/render/literal changes preserving unit and adapter bytes; a non-entry float-render helper carrying its formatter dependency; cross-unit path/caller diagnostics; and direct plus indirect cross-unit aggregate sret calls. Existing trace tests remain green. Guardian's whole-tree gate passes all 88 checks.
