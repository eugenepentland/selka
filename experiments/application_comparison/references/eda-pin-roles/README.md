# eda-pin-roles reference

Coordinator-only reference solution, independently implemented from the task brief
and the Python EDA v1 baseline. This is not a trial participant or a measured
result. Only Python standard-library modules are used. The original baseline is
unchanged; this directory implements only this task, not the other EDA extension.

Run `python3 main.py` with a JSON request on stdin. Run own tests from this
directory with `python3 -m unittest -v test_reference.py`.
