# Full EDA checked ownership migration

The application is the complete `eda-sch` exporter used by the October 9 FS-X comparison: nested S-expression model parsing, library loading, placement, KiCad schematic generation, sidecars and netlist generation. All 121 modules, including the SVG helpers, and all 310 original guest tests are retained. The parser-only `experiments/sexpr-port` benchmark is a different workload.

`original/src` preserves the prepared modern-syntax application from `/home/epentland/ai/canopy/mylang-worktrees/claude-main-ce/.mylang-cache/eda-src/src`. `prepared-source-manifest.json` records its exact files. `source/src` contains the canonically formatted checked migration; `final-source-manifest.json` records its frozen bytes. All public declarations remain present. The original has 21,792 lines and 3 explicit `.copy()` sites; the migration has 21,856 lines and 843 copy sites. `evidence/final/migration-burden.json` gives per-file changes.

`original-source-manifest.json` additionally records the older PM/FS-X cached snapshot at `/home/epentland/ai/canopy/mylang-worktrees/claude-parity-measure/.mylang-cache/cex/eda-src/src`. That snapshot uses retired module headers and positional union variants. Its bytes differ from the prepared modern-syntax source. Historical timing comparisons must distinguish this source change from compiler changes. Fresh controls use the exact preserved modern source and the same frozen compiler as the migration.

Final verification passed all 310 tests in original RC verified release, migrated RC verified release, checked ownership verified release, and checked ownership optimized debug. Every run enables leak checking. The explicit test budgets are 1,000,000,000 steps, 40,000 frames, 2 GiB per test and 120 seconds, with four workers. Initial default-budget failures in the unmodified source were budget traps and are preserved separately.

All 34 frozen cases produce the complete byte-identical file sets in original RC, migrated RC, checked release, checked verified release and checked debug: 170/170 arm-case output sets. Nine CLI, malformed-model and filesystem error paths have identical statuses, stdout and stderr across those five arms. The checked executable has no RC-named LLVM call sites or defined RC symbols. Resource and dictionary destruction helpers named `release` are classified separately. The two legacy executables retain 158 RC-named symbols each. `evidence/final/abi-rc-audit.json` contains the symbol and call counts; complete static call records are preserved in its compressed raw companion. Runtime allocation and exit-live counters are measured separately from the uninstrumented timing binaries.

The migration preserves independently owned return APIs through explicit copies. AST constructors and child/text accessors copy borrowed managed inputs, so nested accesses can clone complete subtrees. Legacy retained `.view(start, end)` operations become independently owned slices. Generic stable sorting copies managed elements during each merge and permutation assignment. These are material costs of the migrated source and remain visible in the original-RC / migrated-RC / checked-ownership comparison. Passing or reading tokenizer fields directly prevents a complete source clone per token. Matching fresh parser and traced-reader call results directly permits successful payload transfers without extra AST or input clones.

Native lowering rejects an otherwise checked nested record-list field update. The compositor uses an explicit owned child copy, updates its field, and publishes the whole child back to the list. The exact rejected shape and compiler log remain in `evidence/repros/nested-record-list-field-writeback.*`; no compiler fallback or unchecked flag is used.

`build-arms.sh`, `qualify-tests.sh`, `check-goldens.py` and `check-error-paths.py` reproduce the build and qualification steps inside an admitted build lease. Eight installed guest executables are frozen read-only under `.tmp/lox-eda-20261012/eda/final`; the LLVM files, build logs, binary hashes and full receipts are retained.
