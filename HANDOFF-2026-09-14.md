## What is done (all merged on the branch)

1. **Managed arenas** replace the old explicit storage tier. `with arena() as x:` region allocation, `x.escape(v)` copy-out, static `E_ARENA_ESCAPE` and runtime `R_ARENA_ESCAPE`.
2. **Python-only syntax.** Brace syntax, `fn let mut struct new :: cast<>`, `//` comments and the `migrate` tool are gone. Keyword count 125 → 83. Payload variants, `case _`, comprehensions, `assert`, f-strings over any value, `str` methods, `divtrunc`, `T(x)` casts, `todo[T]()`.
3. **QBE native backend is the only runtime.** The bytecode interpreter was deleted (~10k lines). `bytecode.zig`/`lower.zig` survive only as the IR QBE consumes. `mylang run` = native build + execute.
4. **Managed `bytes`, stdlib on managed types**, ten modules, every export documented.
5. **I/O and capabilities.** `print`, `open`, file helpers; everything granted by default, `--restrict` opts into deny-by-default.
6. **Executable docs + coverage gates.** Every fenced ```mylang example runs in the gate; every feature slug in `src/features.json` and every stdlib export must have a doc section with a runnable example (`mylang doc-coverage .`).
7. **Cold-build fix.** A prebuilt runtime archive is installed beside the compiler; cold `mylang build` links it instead of compiling the runtime from source. Warm ~0.09 s, cold ~0.24 s (was 1.4 s).
8. **Memory ceiling.** Every guest runs under a byte budget (`R_MEMORY_BUDGET`) backed by an `RLIMIT_AS`; `--max-memory` on run/build/test; `mylang test` sizes its fan-out from free memory. This is what stops a runaway from taking down the host.
9. **Python fold.** No Python runs in any gate; `mylang doctest` is a compiler subcommand; drivers are Zig-native.
10. **`main`'s int is the process exit status** (truncated to 8 bits). `--print-result` still prints the value; a trap still exits 1. This is the item that caused a detour — see "lessons" — but it is settled and green.

## The one remaining item — function-scoped locals (NOT done)

This was in progress when we stopped. The agent was halted with **no commits**, so nothing is on its branch to salvage; start fresh.

- **Goal:** change locals from block-scoped to Python-style function-scoped. Today a name first assigned inside `with`/`if`/`for`/`while` is not visible after the block, which forces awkward pre-declaration. Make an assignment anywhere in a function body one function-scoped binding, visible from first assignment to end of body, with a use-before-assignment static error.
- **Hard requirement:** it must **not** regress arena-escape safety. A local first assigned inside `with arena()` now outlives the block, so `E_ARENA_ESCAPE` (static) and `R_ARENA_ESCAPE` (runtime write-barrier) must still fire for an arena object read after the region is freed. Add a test proving this. If the invariant can't be kept cleanly, stop and reconsider — this is the risky part.
- **Touches:** the checker's scope/name-resolution; `test/integration.zig` and Zig test roots that assert `E_UNKNOWN_NAME` after a block; examples that pre-declare a variable before a block; `CLAUDE.md`'s "Locals are block-scoped" bullet (flip it); SPEC.md and docs/statements.md, docs/python-syntax.md, docs/semantics.md.

## Lessons that cost time (so they don't again)

- **Gate an agent's branch yourself before merging, on a clean cache with disk headroom.** The exit-status agent reported green twice while its full gate was actually failing (buffered output, then a stale cache).
- **A poisoned build cache lies.** The disk-full episode left a truncated cached binary that exited 0; a "regression" that reproduces only on a cache that lived through disk-full/OOM is a cache problem, not a code bug. Rebuild clean before concluding.
- **Disk fills fast.** Agent worktrees each carry a full build cache; 108 GB accumulated once. Prune merged worktrees (`git worktree remove --force` the ones whose HEAD is an ancestor of the branch) when space gets tight.
